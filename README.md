# 📚 Offline Curriculum AI Assistant

An offline Retrieval-Augmented Generation (RAG) chatbot and mathematical rule solver built using **Llama 3.2**, **Ollama**, **ChromaDB**, and **Streamlit**.

## ✨ Key Features
- **100% Offline & Private:** Zero external API keys or internet required after initial setup.
- **Strict Curriculum Boundaries:** Rejects any question outside the uploaded PDF syllabus.
- **Local Python Execution Engine:** Extracts formulas/algorithms (such as Row Echelon Form or numerical methods) from PDFs and calculates exact numerical steps without LLM math hallucinations.

## 🚀 One-Click Quick Start (Windows)
1. Ensure **[Python 3.12](https://www.python.org/downloads/)** and **[Ollama](https://ollama.com/)** are installed on your PC.
2. Click the green **Code** button above and select **Download ZIP**.
3. Extract the folder and double-click **`start.bat`**.
4. The script will automatically set up the environment, download the local models, and launch the app in your browser!
